# FEE-I: Instrumentation-Amplifier-Based Front-End Electronics

## 1. Overview

FEE-I is a front-end electronics design for CMOS image detectors, providing 16 channels of analog signal acquisition together with detector power supplies, bias voltages, clock driving, and monitoring functions.

The system consists of a Fan-Out Board located close to the detector and a Front-End Board connected through cables. The Fan-Out Board employs operational-amplifier voltage followers to buffer the detector output signals.

The Front-End Board contains analog signal conditioning circuits, analog-to-digital converters (ADCs), DAC-based voltage generators, clock buffers, and monitoring and protection circuits.

The complete Front-End Board schematic is available in [FEEI.pdf](/assets/detector-front-end/fee-i/FEEI.pdf).

## 2. Analog Signal Processing

The Front-End Board contains 16 identical analog acquisition channels. Each channel consists of a three-operational-amplifier instrumentation amplifier, an active low-pass filter, and a 16-bit ADC.

The instrumentation amplifier receives two input signals, VinP and VinM, and converts their voltage difference into a single-ended signal. The amplifier provides common-mode rejection and a gain determined by its resistor network.

The signal is then processed by a second-order active low-pass filter with a Bessel response.

An adjustable offset voltage is applied to match the signal range to the unipolar input range of the ADC.

Each channel uses an LTC2364-16 ADC. The ADCs are operated with common conversion timing, and their serial output data are transferred to the digital acquisition electronics.

The analog signal chain was designed for a pixel rate of approximately 200 kHz, corresponding to a 5 µs pixel period. Since the detector output changes from pixel to pixel, the analog signal must settle sufficiently before each A/D conversion. The amplifier and filter circuits were therefore designed to achieve the required settling accuracy within the available pixel period.

The design principles of the instrumentation amplifier, analog filter, and ADC are described in [Analog Signal Processing Design](/projects/detector/front-end/fee-i/analog-design.html), including common-mode rejection, gain and offset adjustment, filter characteristics, and ADC noise performance.

## 3. Power and Bias Generation

The Front-End Board generates programmable power and bias voltages required by the detector.

An AD5628 digital-to-analog converter (DAC) provides eight programmable voltage outputs. Operational-amplifier buffers supply the required output drive capability.

The output currents are measured using current-sense resistors and current-monitor amplifiers. Comparator circuits detect currents outside the specified operating ranges.

A hardware protection circuit is provided to disable the programmable outputs when an abnormal current condition is detected, independently of software control.

## 4. Clock and Control Interface

Clock signals generated by the external digital control electronics are received by the Front-End Board and delivered to the detector through clock interface circuits.

Analog switches are used to select the clock output levels, while digital buffers provide the required logic-level interfaces.

The board also receives control signals for the DACs, ADC conversion, and monitoring circuits. Digitized detector data are transmitted to the external data acquisition electronics through serial interfaces.

## 5. Monitoring

The Front-End Board includes circuits for monitoring detector bias voltages and output currents.

A multiplexer selects the signals to be measured, and a dedicated ADC converts them into digital monitoring data.

The monitoring functions allow the host system to verify the electrical operating conditions of the detector. Current monitoring is also used by the independent hardware protection circuit described in Section 3.
